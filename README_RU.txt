AITU Student Calculator — готовый файл для GitHub Pages

1. В Supabase откройте проект mrbrromdzjecidqgycux → SQL Editor.
   Проверьте и один раз выполните файл AITU_Supabase_Secure_Setup.sql.
   Он сохраняет существующие таблицы и данные, связывает старые профили с
   аккаунтами по email и ограничивает доступ к профилю владельцем.
   Последний SELECT должен показать три правила Students ... . Если есть
   дополнительные разрешающие правила для этой таблицы, их надо проверить
   до публикации, иначе они могут открыть чужие данные.

2. Загрузите index.html в корень отдельного репозитория GitHub Pages
   (или замените текущий index.html этого калькулятора). Не загружайте его
   в репозиторий ReFood — это другой проект.

3. В Settings → Pages выберите Deploy from a branch, main, /(root).
   Откройте адрес сайта. В Account & Sync создайте аккаунт, подтвердите
   письмо, затем войдите. URL и публичный ключ посетителю вводить не нужно.

4. Для проверки измените данные калькулятора, обновите страницу и войдите
   на другом устройстве под тем же аккаунтом. Данные должны загрузиться.

В HTML встроены только URL проекта и publishable key — их можно размещать
в браузере при корректных правилах RLS. Service role key туда нельзя.
Локальная копия данных отделяется по аккаунтам на одном устройстве.

Исходный файл в Downloads не изменён. Этот пакет не меняет Supabase сам:
SQL нужно выполнить в нужном проекте и проверить результат.
